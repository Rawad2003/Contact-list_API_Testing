
## 📖 Overview

This project focuses on **API Testing** for a Contact List application. It was developed as part of a team collaboration to simulate a real-world **Quality Assurance (QA) workflow**, covering all testing phases from planning to reporting.

The project demonstrates structured testing practices including:

* Test planning
* Test case design & execution
* Bug reporting
* Traceability
* Documentation

---

## 🎯 Objectives

* Validate API functionality and reliability
* Ensure correct handling of positive and negative scenarios
* Identify and report defects
* Apply industry-standard QA documentation
* Collaborate effectively within a testing team

---

## 🧪 Scope of Testing

The API testing covered the following modules:

* 🔐 Authentication (Register, Login, Logout)
* 👤 User management
* 📇 Contact management
* ➕ Create contact
* 📖 Retrieve contact(s)
* ✏️ Update contact
* ❌ Delete contact
* ⚠️ Input validation & error handling
* 🔒 Authorization & security scenarios

3. Test Case Design
4. Test Execution (via Postman)

6. Traceability Mapping (RTM)
7. Final Reporting
